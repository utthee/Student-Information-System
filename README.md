# Dot
Dot is a simnple student information system that is created using Python 3.13 along with PyQt5 for a more simple and user-friendly interface. It uses .csv files as data to display general details about students, programs, 
and colleges.
## Features
1. Create, update, and delete student, program, and college entries.
2. Simple pagination function to allow for a more manageable navigation experience.
3. Search and sort operations.
4. Automatically saves information to CSV.
5. Simple tabular interface.
